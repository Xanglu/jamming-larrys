Jamming Larrys — YouTube & Radio Garden
=======================================

A Chrome extension that keeps YouTube or Radio Garden playback in sync between
two people. One person hosts; everyone else follows. No accounts, no server.

INSTALL
-------
1. Unzip this folder somewhere permanent. Chrome loads the extension from
   this folder every time it starts, so do not delete or move it afterwards.
2. Open chrome://extensions in Chrome.
3. Turn on "Developer mode" in the top-right corner.
4. Click "Load unpacked" and pick this folder (the one containing manifest.json).
5. Optional: click the puzzle-piece icon and pin "Jamming Larrys".

Requires Chrome 116 or newer (or a Chromium-based browser such as Edge/Brave).

USE
---
1. Both of you open the same site: a YouTube video, or a Radio Garden station.
2. One person clicks the extension icon and then "Host". A six-character room
   code appears.
3. The other person clicks "Listen", types the code, and presses Join.
4. When the status pill says "in sync", the host's play, pause, seek, speed,
   video and station changes are mirrored automatically.

Both people must use the same site: YouTube for video, Radio Garden for radio.
A listener on the other site is told which site the host is on instead of
trying to sync.

Share the room code privately: anyone with the code and this extension can join.

RADIO GARDEN NOTES
------------------
- Radio Garden is live radio: there is no seeking, and resuming after a pause
  joins the broadcast at its live edge.
- Station changes try to switch in place. When the tab has to reload, the
  browser may require one click — on "Tap to start the radio" or anywhere on
  the page — before audio begins.
- Leave the station playing on the host tab; the pill shows the connection.

TROUBLESHOOTING
---------------
- Stuck on "Connecting…": the public relay network may be unreachable. Retry,
  or try a different network.
- "Direct connection failed": one side is likely behind a strict NAT, VPN or
  corporate firewall that blocks WebRTC. A TURN server is required there.
- Listener audio blocked: click "Tap to resume playback" (YouTube) or "Tap to
  start the radio" (Radio Garden) on the page, or click anywhere on the page.
- Ads on the listener can cause a brief jump; sync corrects itself afterwards.
